# Pyutenum (rspyast)

[English here](README.md)

## 概要

Pyutenum は Python 標準のテストモジュールである `unittest` を使用するよう書かれたテスト名を列挙するコマンドラインツールです。

標準的なテストのルールである `test` から始まる Python スクリプトファイルに書かれた， `test_` から始まるメソッド名を完全な名前で列挙します。列挙したテストはランナーに渡すことで実行可能です。

## インストール

Github のリリースページからお使いの環境に合うバイナリーをダウンロードすることにより利用可能となります。

または，Pyutenum は Rust でできているため Rust の開発環境があればソースコードをビルドしてインストールすることもできます。

```sh
cargo install --path .
```

## 使い方

```sh
./rspyast # カレントディレクトリを基準にテストを列挙します
./rspyast tests # testsディレクトリを基準にテストを列挙します
./rspyast --select # カレントディレクトリを基準に列挙したテストを逐次検索により選択できます
```

Pyutenum はテストの列挙しか行いません。 `grep` や `fzf` でフィルタリングを行いランナーに渡すという使われ方を想定しています。
